Tentang Kami

LPK Pertama di Riau yang Resmi Menjadi Sending Organization

LPK Cahaya Subarashi Indonesia adalah Lembaga Pelatihan Kerja untuk program Magang & Tokutei Ginou ke Jepang. Kami menjadi SO resmi pertama di Riau.

Dipimpin Agung Wasi Ibrahim (Direktur Utama), didukung sekretaris, bendahara, administrasi, dan para sensei bahasa Jepang berpengalaman.

Program Kami

Pilihan Program Pelatihan

Program Magang (Ginou Jisshu)

Pemagangan 3 tahun di Jepang. Pelatihan bahasa N4, budaya kerja, dan interview.

  • ✓ Durasi ±5 bulan
  • ✓ Bimbingan sampai dapat job
  • ✓ Biaya bisa dicicil

Tokutei Ginou

Visa kerja khusus tenaga terampil untuk karier jangka panjang di Jepang.

  • ✓ Manufaktur, perawatan, dll
  • ✓ Persiapan ujian skill
  • ✓ Pendampingan dokumen

Kelas Bahasa Jepang

Dari dasar hingga N4/N5. Tersedia kelas asrama, non-asrama, dan malam.

  • ✓ Sensei lokal & native
  • ✓ Kelas Zoom tersedia
  • ✓ Latihan percakapan intensif
